# \## How do I install?

# 

# Make sure you have Git downloaded: https://git-scm.com/install/

# Open your terminal and type:

# ```git

# git clone https://github.com/Nextbyte-Studios/hashplusplus.git

# ```

# Then navigate to the code folder:

# ```sh

# cd hashplusplus

# ```

# And make sure you have python installed and type in:

# ```sh

# python main.py

# ```
